# SIM 卡槽切换 + MBN 列表与手动选择 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 SIM 卡槽切换（`AT+QUIMSLOT=<n>`）与 MBN 列表查询 + 手动选择（`AT+QMBNCFG="List"` / `AT+QMBNCFG="Select",...`）功能。

**Architecture:** 后端沿用现有"WebSocket action → `AtAction` → 串行 actor（`hardware_task`）→ `HardwareBackend` trait 方法 → `RealBackend`/`MockBackend`"通道。MBN 从 `DiagnosticType` 拆出为独立 trait 方法并结构化返回。前端在 `src/index.html` 单文件内新增卡槽按钮与 MBN 下拉控件，通过 `WS_HANDLERS` 分发响应。

**Tech Stack:** Rust (axum 0.8 + tokio)、atcmd_rs 外部进程执行 AT 命令、纯前端 JS（无框架）。

## Global Constraints

- 目标设备交叉编译 target 为 `armv7-unknown-linux-musleabihf`；开发验证用 host 上 `cargo check` / `cargo test`。
- 依赖必须保持纯 Rust，不得引入 ring/openssl 等 C 依赖。
- **不修改 `templates/` 目录下的任何内容**。
- AT 命令参数必须经 `sanitize_at_param` 过滤（去引号/反斜杠/控制字符），防 AT 注入。
- `HardwareBackend` trait 新增方法必须同时在 `RealBackend` 与 `MockBackend` 实现，否则编译失败。
- 遵循现有 actor 串行化模式（0 锁），新逻辑不得引入 Mutex/全局可变状态。
- 提交信息使用中文，前缀 `feat:`/`refactor:`/`test:`/`docs:`。

```rust
    async fn set_sim_slot(&self, slot: u32) -> Result<String, String> {
        if !matches!(slot, 1 | 2) {
            return Err(format!("无效的 SIM 卡槽，仅支持 1/2: {}", slot));
        }
        send_at_command_inner(&self.serial_path, &format!("AT+QUIMSLOT={}", slot)).await
    }

    async fn get_mbn_list(&self) -> Result<Vec<serde_json::Value>, String> {
        let resp = send_at_command_inner(&self.serial_path, "AT+QMBNCFG=\"List\"").await?;
        let entries: Vec<serde_json::Value> = resp
            .lines()
            .filter_map(|line| {
                match at::parser::parse_single_line(line.trim()) {
                    Some(at::parser::ParsedLine::Qmbncfg(e)) => {
                        Some(serde_json::json!({ "index": e.index, "state": e.state, "name": e.name }))
                    }
                    _ => None,
                }
            })
            .collect();
        if entries.is_empty() {
            Err(format!("未解析到 MBN 列表: {}", resp.trim()))
        } else {
            Ok(entries)
        }
    }

    async fn set_mbn(&self, name: &str) -> Result<String, String> {
        let name = sanitize_at_param(name);
        if name.is_empty() {
            return Err("MBN 名称不能为空".to_string());
        }
        send_at_command_inner(&self.serial_path, &format!("AT+QMBNCFG=\"Select\",\"{}\"", name)).await
    }
```

```js
            if (!el) return;
            if (data.success) {
                el.innerHTML = '<span class="text-amber-500 dark:text-amber-400 font-semibold">✓ ' + escapeHtml(data.msg || '选择成功') + '，⚠ ' + escapeHtml(data.note || '需重启生效') + '</span>';
            } else {
                el.innerHTML = '<span class="text-red-500 font-semibold">✗ ' + escapeHtml(data.msg || '选择失败') + '</span>';
            }
        }

        function initMbnPanel() {
            const refreshBtn = getDomElement('mbn_refresh_btn');
            if (refreshBtn) {
                refreshBtn.addEventListener('click', () => {
                    const el = getDomElement('mbn_status');
                    if (el) el.innerHTML = '<span class="text-amber-500 dark:text-amber-400 font-semibold">⏳ 正在查询 MBN 列表...</span>';
                    sendWsCommand('get_mbn_list');
                });
            }
            const applyBtn = getDomElement('mbn_apply_btn');
            if (applyBtn) {
                applyBtn.addEventListener('click', () => {
                    const name = getDomElement('mbn_select')?.value || '';
                    if (!name) {
                        const el = getDomElement('mbn_status');
                        if (el) el.innerHTML = '<span class="text-red-500 font-semibold">请先刷新并选择一个 MBN</span>';
                        return;
                    }
                    sendWsCommand('set_mbn', { name });
                    const el = getDomElement('mbn_status');
                    if (el) el.innerHTML = '<span class="text-amber-500 dark:text-amber-400 font-semibold">⏳ 正在应用 MBN...</span>';
                });
            }
        }
```
